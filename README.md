# Lazy Witch's Factory 生産計算機（非公式）

ゲーム **[Lazy Witch's Factory](https://store.steampowered.com/app/3971650/Lazy_Witchs_Factory/)** の
契約の効果を数字で確かめるための、ブラウザだけで動く非公式ツールです。

### ▶ **<https://kiyonakanata.github.io/lwf-calc/>**

**シナジー・コンボ選定ツール**です。開発後援（スポンサー3体）を選ぶと、
その構成で手に入る**契約・注文・依頼看板・レシピ**が一覧になり、
契約を取るとレシピの生成個数 / 所要時間 / 生産速度 / 材料消費 / 買取価格が補正後の値に一斉に変わります。

- **📋 レシピ計算** — 使い魔ごとの表に全レシピを並べ、契約・レリック・バフ・ポータル・返済特典の補正が乗ります。
  配置台数を入れると **Σ集計**（資源の増減/s・現金・中間材料の不足・必要な採掘ゴブリン数）が出ます。
  依頼看板でしか手に入らない一期一会のレシピ143件も、引けたものだけ足して比べられます。
- **📇 契約・注文・看板** — 選んだ悪魔ごとに、契約の全一覧（効果つき・その場で取得可）、
  注文の報酬テーブル、依頼看板でもらえるものを並べます。
- **取得順で結果が変わる** — 契約は取った順に上から計算。同じ契約を離れたタイミングで取り直す手順も組めます
  （圧縮・希釈は取った時点で解禁済みのレシピにしか掛からない、というゲームの挙動も再現）。
