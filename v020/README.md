# 📈 返済シミュレーター（v0.20 凍結版）

[← 通常版のREADME](../README.md) ／ このバージョンを開く: <https://kiyonakanata.github.io/lwf-calc/v020/>

**返済ノルマの到達時間を予測するシミュレーター**を含む v2.1.0 です。
契約スキルの重ねがけ設定から現金収入を出し、返済1回ごとのタイムライン（📈グラフ・在庫推移・貢献度）、
ゲームと同じ抽選で契約を選ぶ🎲ドラフト、⛏土地ごとのゴブリン割当（採掘収入・原料収支）まで揃っています。

> **ゲーム ver 0.20.0（体験版）準拠のまま凍結しています。今後は更新しません。**
> アーリーアクセス版でマモン・ベルフェゴールが加わって以降、返済計画ツールとしては前提が合わなくなったため、
> 体験版（開発後援＝ルシファー／レヴィアタン／サタン固定）の環境ごと保存したものです。
> 現行バージョンの計算には [通常版](https://kiyonakanata.github.io/lwf-calc/)（シナジー・コンボ選定ツール）を使ってください。

## 何ができるか

- **レシピ計算**: 契約スキルの重ねがけで全レシピの製造数・所要時間・材料・買取がどう変わるかを一括表示
- **返済シミュレーター**: 選んだレシピと採掘収入から、返済1回ごとの所要時間・累計・在庫推移を予測
  - 📈 タイムライン（別窓・最前面）: 累計収入と返済ライン・在庫推移・収入の貢献度・取得プラン編集
  - 🎲 契約取得をゲーム再現: 実機と同じ確率・手札3枚＋スキップの抽選で契約を選ぶ
  - ⛏ 採掘: 土地ごとのゴブリン割当 → 原料/秒・原料収支・砥石現金（不足の自動補填つき）
- **v0.19 再現モード**は別の凍結版 [v019/](../v019/) にあります（マップ生成から1ゲーム丸ごと再現）

- ゲーム ver 0.21 以降とは、速度バフの重なり方（乗算→加算）・上位金属のレシピと売却値などが異なります
