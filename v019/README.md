# 🎮 再現モード（v0.19 凍結版）

[← 通常版のREADME](../README.md) ／ このモードを開く: <https://kiyonakanata.github.io/lwf-calc/v019/>

**1ゲーム（30分）をまるごと再現するシミュレーター**です。
マップ生成・土地購入・ゴブリン配置・契約の抽選・注文・ポータル・杖まで、ゲームと同じ手順で進めて
**完済タイムを競う**ことができます。

> **ゲーム ver 0.19.0 準拠のまま凍結しています。今後は更新しません。**
> ver 0.20 で「レア以上の契約は再利用不可」になったため、契約を重ねがけし放題だった 0.19 環境ごと保存したものです。
> 現行バージョンの計算には [通常版](https://kiyonakanata.github.io/lwf-calc/) を使ってください。

## 進め方

**「📝 予約する ⇔ ▶ 次のイベントで時間を進める」の繰り返し**です。

1. **🏁 開始条件**を決める … 難易度・Seed・🎖返済特典（0:00でのみ変更可）
2. **🎲 マップ生成** … Seedからマップを作ります（リロール可・「Seed維持」でやり直しても同じマップ）
3. **📝 予約** … ゴブリン配置・レシピ台数・🛒土地購入プラン・注文の☑・契約・杖・ポータルを指定
4. **▶ 次のイベントで時間を進める** … 予約どおりに時間が進み、返済・注文達成などのイベントで止まります

時間は **⌨ ← / →** で自由に行き来できます。計算は常に開始時点からの予測なので、過去に戻って予約を変えても壊れません。
細かい挙動は各パネルの **❓** とホバー説明にあります。

- **🛒 土地購入**: 上から順に自動購入（先頭が買えない間は後続も待つ）。有料購入ごとに価格×3。土地代は注文より優先。🎫無料券は所持していれば強制消費（ゲーム準拠）。
- **🏆 リザルト**: 完済すると難易度別の**自己ベスト**が記録され（ブラウザ内に保存）、「▶再現」でその run を復元できます。
- **📋 RUNコード**: run 全体を1つのコードにして共有・復元できます（「📥 読み込み」で復元）。

## ゲームとの違い（シミュ上の割り切り）

再現とはいえ、以下は意図的に簡略化しています。タイムを比べるときは前提として見てください。

- **物流の要素なし** … コンベア・搬出上限・運搬のボトルネックは存在しません（コンベア系の報酬は記録のみ）。
- **製造の充填待ちなし** … 毎秒◯個の連続レート近似（速度自体は同じ。個数が小さい場面は達成タイミングが数秒ズレます）。
- **採掘速度・クリティカルは期待値** … 上振れ・下振れはありません。
- **ポータルへの納品は自動分配** … アイテム指定の要求を優先し、現金要求が複数なら分割。ベルト配線で偏らせる工夫は再現しません。
- **中間素材は自動で受け渡し** … 消費が先・余りは自動で納品売却（不足なら消費側が停止）。
- **配置は所持の範囲で上から自動充足** … ゲームのように1体ずつ手で置く操作はありません。
- **契約「地下水凝固」は対象外**（コンベア数に依存するため）。
- **Seed はこのシミュ内の再現用** … 同じSeedでもゲームの実プレイとは一致しません（実プレイを写すときは、セル詳細の編集と契約・注文の手動選択で合わせます）。
